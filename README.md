# Subnautica VR - Édition Française (SubmersedVR 6DOF)
### Par LordMadTrix

Ce projet transforme **Subnautica** en une aventure sous-marine 6DOF complète pour Meta Quest 3, Valve Index et casques PCVR.

## Fonctionnalités
- **Contrôles 6DOF des Mains** : Gants de plongée virtuels, scanner interactif, pilotage manuel du Seamoth et Cyclops.
- **Upscaling IA OpenXR** : Eaux cristallines et textures sous-marines nettes sans scintillement.
- **Optimisation Quest 3 120Hz** : Profil Wi-Fi 6 haute fluidité.
- **Installateur Dédié Thématique** : `SubnauticaVR-Setup.exe`.
